# Security Policy

## Supported Versions

LeadDirect-MCP is an open-source tool for agentic outbound lead generation. We currently provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a top priority for our outbound lead generation tools, especially since we handle web scraping, API connections, and contact data processing.

If you discover a security vulnerability within LeadDirect-MCP, please do not disclose it publicly.

Instead, please send an email to the repository maintainer or open a private security advisory on GitHub.

We will endeavor to respond to all reports within 48 hours and work with you to patch the vulnerability and release a secure update as quickly as possible.

### What to include in your report

- A descriptive title
- A description of the vulnerability, including its impact and any potential exploits
- Steps to reproduce the vulnerability
- Any suggested fixes or mitigations

Thank you for helping us keep LeadDirect-MCP safe and secure for the community!
